# public/catalogue - catalogue PDF assets

This folder is regenerated by:

```powershell
npm run export-pdfs
```

The fallback PDFs are exported from the refreshed catalogue files in
`final-deliverables/` using Microsoft Excel, so the owner's existing print
layout is preserved. They live under `fallback/` so the public catalogue
download URLs can be handled by dynamic routes that serve the latest uploaded
owner catalogue first.

| PDF | Source workbook |
| --- | --- |
| `fallback/metals-catalogue.pdf` | `final-deliverables/Metals catalogue 2023.xlsx` |
| `fallback/mini-catalogue.pdf` | `final-deliverables/Mini Catalogue Self Updating.xlsm` |

These PDFs are tracked in git as the fallback when no owner upload exists.
